# Methodology

1. Define written scope and verify the lab target is local and authorized.
2. Record operating system, target, tool versions, date/time, and exact commands.
3. Start with service discovery and HTTP inspection; use safe, non-destructive settings.
4. Save raw outputs, then write a separate interpretation note.
5. Assign confidence and severity based on evidence and context.
6. Validate scanner alerts manually and record limitations.
7. Recommend remediation, assign an owner, and retest after changes.

## Evidence rules
Do not fabricate output, screenshots, or scan reports. Do not describe planned exercises as completed. Redact secrets and unrelated personal/system data before sharing.
